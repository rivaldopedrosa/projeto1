## Visão geral

Projeto Next.js 16 (App Router) com TypeScript e Tailwind CSS 4, usando `src/` e o alias de import `@/*` → `src/*`. O `index.html` na raiz é um resquício estático anterior e não faz parte do app Next.js. Veja também `AGENTS.md`.

## Comandos

- `npm run dev` — servidor de desenvolvimento (http://localhost:3000)
- `npm run build` — build de produção
- `npm run start` — serve o build
- `npm run lint` — ESLint

Não há testes configurados.
